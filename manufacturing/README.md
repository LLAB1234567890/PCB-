# V3.2 2L 制造与装配

独立使用本目录对应的PCB、Gerber ZIP、BOM_JLC和CPL_JLC；不要混用另一版。

FR4、1.6mm，双面1oz。工艺沿用嘉立创；无阻抗控制声明、无假定指定PP/core厚度。外形102.48×71.12mm包络、6个2.7mm NPTH、镀槽已分开输出；最终钻孔总数594。

130个双面SMT器件列入贴片BOM/CPL；21个插件/电源模块/DevKit等另列BOM_Manual_THT_modules。手装母座、跳帽、板外电机/驱动/K1/按钮/传感器/线束不误计CPL。板外采购依据见sources和报告的整机台账。

位置坐标为PCB辅助原点并转换到装配X/Y；下层旋转/镜像按KiCad规则导出并回读校验。工厂库旋转偏置不等于几何校验，订单预览应逐件核对pin1、光耦、MOS、D9/TVS、蜂鸣器正负。实际库存/交期以工厂当前确认，未擅自替换MPN。

回流/清洗条件按真实手册；安装后普通USB供电必须断开J19。工厂拼板/工艺边不加入固定成品板框，由订单面板处理。

制造一致性见validation/CONSISTENCY_R2_manufacturing.json；所有源SHA绑定。样机电气/EMC/温升/停止距离/实际机械适配仍未执行。
